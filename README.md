📘 College Chatbot API (TF-IDF Based)
Overview

This project is a lightweight FAQ chatbot built using TF-IDF vectorization and cosine similarity. It matches user queries with predefined question-answer pairs and returns the most relevant response.

There’s no fancy deep learning here — just efficient, interpretable NLP that works well for structured datasets like college FAQs.

🚀 Features
TF-IDF based semantic matching
Synonym expansion for better query understanding
Cosine similarity scoring
Confidence-based filtering (avoids wrong answers)
Simple JSON-based knowledge base
Fast and lightweight (no heavy models)
